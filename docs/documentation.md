# Офицальная документация к фреймворку Bullsploit

Все взаимодействие с bullsploit framework в документации происходит на машине с arch linux.

После установки фреймворка и запуска ядра по короткой инструкции из README на главной странице гитхаб репозитория, вы увидите подобный вывод в консоль:

<img width="874" height="372" alt="image" src="https://github.com/user-attachments/assets/b7fad69b-380d-437c-af21-2aaeca1da778" />

Это исходное состояние фреймворка и его главное меню с приглашением к вводу в bsc (bullsploit console). В меню отображается логотип с быком, где около него написано dev#1.1, где 1.1 обозначает текущую версию последнего релиза.
Для того, чтобы начать работу с фреймворком нужно узнать, какие же команды доступны в этом CLI приложении, для этого введем команду help в bsc:

<img width="866" height="624" alt="image" src="https://github.com/user-attachments/assets/3b7f67af-b5be-462b-86fb-e24ca8f21347" />

Как можем увидеть, нам доступны следующие команды:

help - просмотреть доступные команды
    
search <moduletype> - искать модуль по его типу (payload/post/auxiliary/builder)

usagr - посмотреть условия пользования и отказ от ответственности через less

github - открыть страницу с офицальным репозиторием на гитхаб

site - открыть сайт https://bullsploit.ru/framework

clear - очистить терминал

use <module path> - использовать модуль
    
set <arguments> - применить настройки к выбранному модулю
    
run - запустить выбранный модуль
    
exit - завершить процесс программы bullsploit
    
interact - войти в режим реверс шелла с доступным клиентом
    
options - посмотреть доступные опции для выбранного модуля
    
sessions - посмотреть доступные сессии
    
show - просмотреть измененные параметры для текущего модуля
    
back - отменить выбор

Чтобы начать полноценную работу с фреймворком необходимо для начала выбрать модуль, с которым мы хотим работать. Чтобы найти подходящий модуль, введем команду search, которая выводит в таблице
все найденные модули по структуре: номер, имя, дата создания, уровень, краткое описание.
